# Cheezy Bytzz — Restaurant Website

A mobile-first restaurant website for Cheezy Bytzz in Jogeshwari West, Mumbai. Built with static HTML, CSS and vanilla JavaScript; no build step or package install is required.

## Features

- Responsive desktop, tablet and phone layouts
- Mobile navigation and fixed Menu / Call / Order action bar
- Searchable menu with category filters
- Sample prices based on public online listings
- Direct Swiggy, Zomato, call and Google Maps links
- Lazy-loaded food photography and social-sharing metadata

## Netlify

Publish directory: repository root. No build command required.

## Confirm before official use

Menu prices may change with size, customization, delivery platform and offers. Food photos are representative, not guaranteed photos of the exact servings. Confirm phone number, address, hours and menu with the restaurant.
